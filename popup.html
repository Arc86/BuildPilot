Build Agent Autopilot

Open Build Agent first

Autopilot runs on ServiceNow instances (*.service-now.com). Open Build Agent there, then click the extension again.

For dev and demo instances only

Autopilot approves Build Agent's plans, scripts and changes without showing them to you, including changes that could delete data. Don't use it on customer, production or shared instances, or anywhere with sensitive data.

Enable autopilot on ?

Only for personal dev or demo instances. Chrome will ask to give autopilot access to this instance.
